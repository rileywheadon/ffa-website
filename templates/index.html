Flood Frequency Analysis Framework

This is a web interface for the flood frequency analysis (FFA) framework developed in Vidrio-Sahagun et al. 2024. The framework provides tools for both stationary and nonstationary FFA as well as exploratory data analysis. In addition to this website, the framework can be accessed through a R package. For more information about the framework, see here.

To use this website, click on the “Get Started” button below. Then, you will be guided through the following five modules:

  • Dataset selection
  • Exploratory data analysis
  • Approach selection
  • Frequency analysis
  • Report generation

This work was funded by the Flood Hazard Identification and Mapping Program of Environment and Climate Change Canada, as well as the Canada Research Chair (Tier 1) awarded to Dr. Alain Pietroniro.

ATTENTION: We strongly recommended screening data for missing entries and low/high outliers before using this framework. The 'CSHShydRology' and 'tidyhydat' R packages can help with this.
